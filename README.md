## 📂 Repository Structure

Each blog post is stored as a Markdown (.md) file. Files are automatically generated and synced via the Hashnode–GitHub integration.

- Each blog post is stored as a **Markdown file (.md)**
- File names follow this pattern: `draft-<hash>.md`
- Example: `draft-6967ef9b99050dad21527b64.md`

This structure ensures traceability between published articles and their source backups.
